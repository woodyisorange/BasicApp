# Basic App
## Overview
A basic application that builds on Windows and Linux, providing a test bed for the common application and math layers shared between my other projects.

## Building
### Windows
Requires a command prompt with MSVC on the path (e.g. Visual Studio Developer Command Prompt, or after running vcvars).
#### Debug Build
> nmake debug

#### Release Build
> nmake release

### Linux
Requies a terminal with clang++ on the path.
#### Dependencies
- Clang
- X11
#### Debug Build
> make debug

#### Release Build
> make release
